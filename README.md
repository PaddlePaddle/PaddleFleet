## ⚡ Quick Start

```bash
# 1. Clone repository for examples
git clone https://github.com/PaddlePaddle/PaddleFleet.git
cd PaddleFleet
curl -LsSf https://astral.sh/uv/install.sh | sh # Install uv in linux and macOS
uv sync # Sync all dependencies
uv build # Build whl packages
uv run pytest # Run tests
```
